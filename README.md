# HOWIYA | هُوية

منصة أعمال لمصمم هويات بصرية، مبنية باستخدام React وJavaScript وVite. الواجهة عربية افتراضيًا مع دعم الإنجليزية وRTL/LTR، ومظهر فاتح وداكن.

## رابط النسخة التجريبية

https://add866705-afk.github.io/hawiya/

## ما يتضمنه المشروع

- صفحات الرئيسية، من أنا، الأعمال، تفاصيل كل مشروع، التواصل، و404.
- خمسة مشاريع مفاهيمية تجريبية قابلة للاستبدال بأعمال حقيقية.
- صفحة تفاصيل لكل مشروع تشمل الملخص والتحدي والاستراتيجية والحل والألوان ومعرض الصور.
- تصفية الأعمال حسب المجال.
- معرض صور مع نافذة تكبير.
- خدمات ومحتوى تعريفي وآراء العملاء (تُضاف الآراء الحقيقية من لوحة الإدارة).
- دعم العربية والإنجليزية واتجاه RTL/LTR.
- مظهر فاتح وداكن مع حفظ التفضيلات.
- لوحة إدارة تجريبية لإدارة المشاريع والخدمات والملف التعريفي والروابط والرسائل وإعدادات SEO.
- حفظ محلي في LocalStorage، مع ترحيل آمن للبيانات القديمة والتعامل مع تعطل التخزين.
- GitHub Actions للتحقق من البناء والنشر إلى GitHub Pages.

## المتطلبات والتشغيل المحلي

يتطلب المشروع Node.js 18 أو أحدث.

```bash
npm install
npm run dev
```

أوامر التحقق:

```bash
npm run build
npm run preview
```

## حدود النسخة الحالية — مهم قبل الإطلاق التجاري

هذه نسخة واجهة أمامية تجريبية، وليست نظام إدارة محتوى إنتاجيًا بعد:

- تسجيل الدخول التجريبي يعمل داخل المتصفح ويمكن تجاوزه؛ لا تستخدمه لحماية بيانات أو محتوى حساس.
- المشاريع والخدمات والملف التعريفي والرسائل تُحفظ في LocalStorage على جهاز الزائر فقط، ولا تتزامن بين الأجهزة أو المستخدمين.
- نموذج التواصل لا يرسل بريدًا ولا ينقل الرسائل إلى صاحب الموقع. تظهر الرسالة داخل لوحة الإدارة في المتصفح نفسه فقط.
- لا توجد قاعدة بيانات أو رفع ملفات إلى خادم. الصور الحالية روابط خارجية، ويمكن إضافة روابط صور مباشرة من لوحة الإدارة.
- بيانات المشاريع الحالية مفاهيمية تجريبية، وليست أعمال عملاء حقيقية. لا تنسبها إلى عملاء فعليين.
- لا توجد حماية خادمية أو صلاحيات متعددة المستخدمين.

قبل استخدام الموقع تجاريًا، اربط Supabase Auth للمصادقة، وPostgreSQL للمحتوى، وStorage للصور، وسياسات RLS للصلاحيات، وخدمة بريد أو وظيفة خادمية لمعالجة رسائل التواصل. لا تضع مفاتيح `service_role` داخل ملفات الواجهة أو متغيرات Vite العامة.

## إعداد Supabase المستقبلي

يوجد ملف إعداد تمهيدي في `src/services/supabaseConfig.js`. ملف `.env.example` يوضح أسماء المتغيرات المطلوبة. ثبّت مكتبة `@supabase/supabase-js` فقط عند بدء تنفيذ التكامل، واستخدم مفتاحًا عامًا محدود الصلاحيات في المتصفح، مع RLS مفعّلًا.

## الصور والخطوط

- صور المشاريع التجريبية مستضافة على Unsplash وتتطلب اتصالًا بالإنترنت.
- الخطوط IBM Plex Sans Arabic وDM Sans تُحمّل من Google Fonts.
- في حال تعذر الوصول إلى هذه الخدمات، يستخدم المتصفح الخطوط البديلة.

## بنية الملفات

- `src/components`: مكونات مشتركة.
- `src/layouts`: تخطيطات الموقع العام ولوحة الإدارة.
- `src/pages`: صفحات الموقع.
- `src/admin`: تسجيل دخول الإدارة وإدارة المحتوى والمشاريع.
- `src/context`: حالة التطبيق واللغة والمظهر والبيانات.
- `src/data`: بيانات العرض التجريبية.
- `src/services`: التخزين والتحقق ونقطة إعداد Supabase.
- `src/localization`: نصوص العربية والإنجليزية.
- `src/styles`: أنماط التصميم.
- `.github/workflows`: فحوصات البناء والنشر.

راجع `docs/RELEASE_CHECKLIST.md` قبل الإعلان عن الموقع كخدمة إنتاجية.
