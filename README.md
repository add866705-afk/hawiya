# HOWIYA | هُوية

منصة أعمال لمصمم هويات بصرية، مبنية باستخدام React وJavaScript وVite.

## المتطلبات والتشغيل
يتطلب المشروع Node.js 18 أو أحدث.
```bash
npm install
npm run dev
```
أوامر أخرى: `npm run build` لإنشاء نسخة الإنتاج، و`npm run preview` لمعاينتها.

## ما يتضمنه الإصدار
- الرئيسية، من أنا، المشاريع، تفاصيل المشروع الديناميكية، التواصل، وصفحة 404.
- خمسة مشاريع تجريبية بمعارض صور وفلاتر تصنيف وقصص مشاريع وألوان ووسوم.
- العربية والإنجليزية مع RTL/LTR، والمظهر الفاتح والداكن وحفظ التفضيلات.
- لوحة إدارة تجريبية للمشاريع مع إضافة وتعديل وحذف ونشر/إلغاء نشر ومعاينة قبل الحفظ وترتيب صور المعرض عبر ترتيب الروابط.
- إدارة بيانات المصمم والخدمات والآراء ورسائل نموذج التواصل وروابط التواصل وإعدادات SEO واللون واللغة الافتراضية.
- تغيير كلمة مرور دخول النسخة التجريبية.
- حفظ البيانات في LocalStorage، ونموذج تواصل يتحقق من المدخلات ويحفظ الرسائل داخل المتصفح.
- Error boundary وGitHub Actions للتحقق من بناء المشروع.

## بيانات الدخول التجريبية
- المسار: `/admin/login`
- البريد: `admin@howiya.local`
- كلمة المرور الافتراضية: `HowiyaDemo2026!`

يمكن تغيير كلمة مرور النسخة التجريبية من إدارة المحتوى والإعدادات. تحفظ محليًا في المتصفح.

**تحذير أمني:** كل ما يتعلق بالمصادقة والتفويض وتخزين المحتوى في هذا الإصدار يعمل على جهة العميل فقط. بيانات الدخول قابلة للاكتشاف أو التجاوز من أدوات المطور، كما أن LocalStorage ليس قاعدة بيانات آمنة أو مشتركة بين الأجهزة. لا تستخدمه لحفظ بيانات حقيقية. قبل الإطلاق الفعلي استبدل ذلك بـSupabase Auth وPostgreSQL وStorage وسياسات RLS، وتحقق من الصلاحيات والمدخلات على الخادم. لا تضع مفاتيح service_role داخل تطبيق المتصفح.

## نشر GitHub Pages
بعد دمج التغييرات إلى الفرع `main`، يعمل Workflow النشر تلقائيًا. عنوان الموقع المتوقع لمستودع المشروع هو:

`https://add866705-afk.github.io/hawiya/`

يستخدم الموقع HashRouter حتى تعمل روابط الصفحات التفصيلية عند الاستضافة الثابتة. يجب أن تكون GitHub Pages متاحة للحساب والمستودع؛ المستودعات الخاصة تحتاج خطة GitHub تدعم Pages للمستودعات الخاصة. لا تجعل المستودع عامًا دون مراجعة أثر ذلك على خصوصية الشيفرة.

## إعداد Supabase المستقبلي
انسخ `.env.example` إلى `.env`، ثم ضع عنوان المشروع ومفتاح anon/public فقط. يوجد ملف `src/services/supabaseConfig.js` كنقطة ربط أولية. عند الانتقال للإنتاج، ثبّت `@supabase/supabase-js` وأنشئ طبقة API فعلية بدل محول LocalStorage.

## الصور
روابط صور العرض من Unsplash، وتحتاج اتصالًا بالإنترنت. يمكن تغيير روابط الصور وترتيب المعرض من لوحة إدارة المشاريع.

## بنية المصدر
- `src/components`: مكونات واجهة مشتركة وErrorBoundary.
- `src/layouts`: تخطيطات الموقع ولوحة الإدارة.
- `src/pages`: صفحات الموقع العام.
- `src/admin`: إدارة المحتوى.
- `src/context`: اللغة والمظهر والبيانات والجلسة التجريبية.
- `src/data`: بيانات المشاريع التجريبية.
- `src/services`: التخزين والتحقق ونقطة إعداد Supabase.
- `src/localization`: قاموس الترجمة.
- `src/styles`: الأنماط العامة.

هذا إصدار تأسيسي قابل للتطوير؛ لا يُعد CMS أو نظام مصادقة إنتاجيًا حتى ربطه بخدمات خلفية موثوقة.
