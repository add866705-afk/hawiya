# HOWIYA | هُوية

منصة أعمال احترافية لمصمم هويات بصرية، مبنية باستخدام React وJavaScript وVite.

## المتطلبات والتشغيل
يتطلب المشروع Node.js 18 أو أحدث.
```bash
npm install
npm run dev
```

أوامر أخرى: `npm run build` لإنشاء نسخة الإنتاج، و`npm run preview` لمعاينتها.

## ما يتضمنه هذا الإصدار
- صفحات رئيسية، من أنا، المشاريع، تفاصيل المشروع الديناميكية، التواصل، و404.
- خمسة مشاريع تجريبية بمعارض صور وفلاتر تصنيف.
- العربية والإنجليزية، RTL/LTR، ومظهر فاتح/داكن مع حفظ التفضيلات.
- لوحة تحكم تجريبية لإدارة المشاريع ومحتوى الملف الشخصي والخدمات والآراء وروابط التواصل.
- حفظ محلي في LocalStorage مع فصل طبقة التخزين عن الواجهة.
- تحقق أساسي من نموذج التواصل، ورسائل حالة، وتصميم متجاوب.

## الدخول التجريبي
- المسار: `/admin/login`
- البريد: `admin@howiya.local`
- كلمة المرور: `HowiyaDemo2026!`

**تحذير أمني:** المصادقة في هذا النموذج على جهة العميل فقط. بيانات الدخول ثابتة في كود الواجهة، والجلسة في sessionStorage، لذلك يمكن تجاوزها ولا تصلح للإنتاج. لا تضع بيانات حقيقية أو سرية هنا. قبل النشر الفعلي انقل المصادقة والصلاحيات إلى خادم موثوق واربط Supabase Auth وPostgreSQL وStorage مع سياسات RLS صحيحة، وتحقق من المدخلات على الخادم. لا تضع مفاتيح الخدمة السرية في المتصفح.

## الصور
صور العرض مرتبطة بمصادر Unsplash عبر الإنترنت، ويمكن تعديل روابطها من لوحة إدارة المشاريع. يلزم اتصال إنترنت لعرض هذه الصور.

## بنية المصدر
- `src/components`: عناصر الواجهة المشتركة.
- `src/layouts`: تخطيطات الموقع ولوحة الإدارة.
- `src/pages`: صفحات الموقع العام.
- `src/admin`: صفحات إدارة المحتوى.
- `src/context`: اللغة والمظهر والبيانات.
- `src/data`: المحتوى التجريبي.
- `src/services`: طبقة التخزين والتحقق.
- `src/localization`: قاموس اللغتين.
- `src/styles`: الأنماط العامة.

هذا الإصدار بداية عملية قابلة للتطوير، وليس نظام CMS أو مصادقة إنتاجيًا مكتملًا.
